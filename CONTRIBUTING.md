# Contributing to bedrock-model-compare

Thank you for your interest in contributing! We welcome bug reports, feature suggestions, and pull requests.

## How to contribute

1. **Report Bugs**: Use the GitHub Issues tracker to report bugs. Please include steps to reproduce the issue and your environment details.
2. **Suggest Features**: Open an issue to discuss new features or improvements.
3. **Submit Pull Requests**: 
    - Fork the repository.
    - Create a new branch for your feature or fix.
    - Write clear, documented code.
    - Ensure your changes don't break existing functionality.
    - Submit a pull request with a detailed description of your changes.

## Development Setup

See the [Installation](README.md#installation) section in the README for details on setting up your local environment.

## Code of Conduct

Please be respectful and professional in all interactions.
